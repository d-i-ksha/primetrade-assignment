# Secure Scalable System Core — Primetrade.ai Intern Assignment

A production-ready implementation of a scalable backend API built using **FastAPI** and **SQLAlchemy (SQLite)** combined with an intuitive responsive frontend UI layout framework.

## 🚀 Key Implementation Metrics
- **JWT Auth Suite:** Complete authorization cycle featuring data hashing techniques via `bcrypt`.
- **Role-Based Access Control (RBAC):** Restricts data viewing dynamically. Admins can look up comprehensive platform telemetry (all records), whereas standard users interact exclusively with items bound to their specific configuration keys.
- **Auto-Documented OpenAPI Layer:** Out-of-the-box interactive testing suite built directly inside FastAPI.
- **Input Sanitization & Processing Engine:** Powered entirely by rigid Pydantic validation models.
